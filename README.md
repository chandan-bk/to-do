# Focuslist

A clean, responsive todo list for focused days. Focuslist is a vanilla HTML, CSS, and JavaScript project with no build step or dependencies.

## Features

- Add tasks with low, medium, or high priority
- Mark tasks complete or delete them
- Filter by all, active, or completed tasks
- Search tasks instantly
- Completion statistics and progress ring
- Tasks persist in browser `localStorage`
- Responsive layout for desktop and mobile

## Run locally

Open [index.html](./index.html) in a browser. No installation is required.

## Publish to GitHub

```bash
git init
git add .
git commit -m "Build Focuslist todo app"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

The project can also be deployed with GitHub Pages by selecting the `main` branch and `/ (root)` as the source.
